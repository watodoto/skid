## how to install modmium on a ti50 for skids
this assumes you've already done wp.md

1. `cd /usr/local`
2. `curl -LOsk modmium.dev/modmium.sh`
3. `bash modmium.sh --nobackup`
4. press y twice
5. wait
6. once it tells you to reboot then run `reboot` in vt2
7. boot from internal disk
8. Ctrl alt refresh again
9. `cd /usr/local`
10. `bash modmium.sh`
11. just press y for anything it asks you at the end
12. once it reboots
13. boot from internal disk (modmium will force you into the correct mode anyway so this is if you're lazy)
14. boom done you have modmium
